# Полное описание столбцов Home Credit Default Risk

В этом документе представлено полное описание всех столбцов по каждой таблице из оригинального файла `HomeCredit_columns_description.csv`.

## 1. Таблица: application_train.csv / application_test.csv
*Основная таблица с данными о заявках на кредит (статистические, демографические данные и т.д.). Каждая строка — это один кредит.*

| Column (Английский) | Description (Русский) |
| --- | --- |
| **SK_ID_CURR** | Уникальный идентификатор текущей заявки на кредит. |
| **TARGET** | Целевая переменная (1 - просрочка более 1 дня / проблемы с выплатами, 0 - все выплачено вовремя). |
| **NAME_CONTRACT_TYPE** | Тип кредита (наличными или возобновляемая кредитная линия). |
| **CODE_GENDER** | Пол клиента. |
| **FLAG_OWN_CAR** | Флаг наличия автомобиля (Y/N). |
| **FLAG_OWN_REALTY** | Флаг наличия недвижимости (Y/N). |
| **CNT_CHILDREN** | Количество детей у клиента. |
| **AMT_INCOME_TOTAL** | Общий доход клиента. |
| **AMT_CREDIT** | Сумма кредита. |
| **AMT_ANNUITY** | Ежемесячный платеж (аннуитет) по кредиту. |
| **AMT_GOODS_PRICE** | Стоимость товара, на который берется кредит (для потреб. кредитов). |
| **NAME_TYPE_SUITE** | Кто сопровождал клиента при оформлении кредита (один, с семьей и т.д.). |
| **NAME_INCOME_TYPE** | Тип занятости/дохода (работает, госслужащий, пенсионер и т.д.). |
| **NAME_EDUCATION_TYPE** | Уровень образования клиента. |
| **NAME_FAMILY_STATUS** | Семейное положение. |
| **NAME_HOUSING_TYPE** | Жилищные условия (собственная квартира, аренда, живет с родителями и т.д.). |
| **REGION_POPULATION_RELATIVE** | Нормализованная плотность/численность населения в регионе клиента. |
| **DAYS_BIRTH** | Возраст клиента в днях (указывается как отрицательное число от текущего дня). |
| **DAYS_EMPLOYED** | Сколько дней назад клиент начал работать на текущем месте (отрицательное число). |
| **DAYS_REGISTRATION** | Сколько дней назад клиент изменил регистрацию. |
| **DAYS_ID_PUBLISH** | Сколько дней назад клиент менял документ, удостоверяющий личность. |
| **OWN_CAR_AGE** | Возраст автомобиля клиента в годах. |
| **FLAG_MOBIL** | Указал ли клиент номер мобильного (1 - да, 0 - нет). |
| **FLAG_EMP_PHONE** | Указал ли клиент рабочий телефон. |
| **FLAG_WORK_PHONE** | Указал ли клиент домашний рабочий телефон. |
| **FLAG_CONT_MOBILE** | Дозвонились ли до клиента по мобильному. |
| **FLAG_PHONE** | Указал ли клиент домашний телефон. |
| **FLAG_EMAIL** | Указал ли клиент email. |
| **OCCUPATION_TYPE** | Профессия / вид деятельности клиента. |
| **CNT_FAM_MEMBERS** | Количество членов семьи клиента. |
| **REGION_RATING_CLIENT** | Рейтинг региона клиента (1, 2, 3). |
| **REGION_RATING_CLIENT_W_CITY** | Рейтинг региона клиента с учетом города. |
| **WEEKDAY_APPR_PROCESS_START** | День недели, когда была подана заявка. |
| **HOUR_APPR_PROCESS_START** | Час, когда была подана заявка. |
| **REG_REGION_NOT_LIVE_REGION** | Флаг совпадения региона регистрации и проживания (0 - совпадают, 1 - нет). |
| **REG_REGION_NOT_WORK_REGION** | Флаг совпадения региона регистрации и работы. |
| **LIVE_REGION_NOT_WORK_REGION** | Флаг совпадения региона проживания и работы. |
| **REG_CITY_NOT_LIVE_CITY** | Флаг совпадения города регистрации и проживания. |
| **REG_CITY_NOT_WORK_CITY** | Флаг совпадения города регистрации и работы. |
| **LIVE_CITY_NOT_WORK_CITY** | Флаг совпадения города проживания и работы. |
| **ORGANIZATION_TYPE** | Тип организации, в которой работает клиент. |
| **EXT_SOURCE_1 / 2 / 3** | Нормализованные скоринговые баллы из 3 внешних источников. |
| *(Блок данных о жилье)* | *Следующие переменные имеют суффиксы _AVG (среднее), _MODE (мода), _MEDI (медиана) и описывают параметры здания, где живет клиент.* |
| **APARTMENTS_...** | Площадь квартиры. |
| **BASEMENTAREA_...** | Площадь подвала. |
| **YEARS_BEGINEXPLUATATION_...** | Год ввода в эксплуатацию. |
| **YEARS_BUILD_...** | Год постройки. |
| **COMMONAREA_...** | Площадь мест общего пользования. |
| **ELEVATORS_...** | Количество лифтов. |
| **ENTRANCES_...** | Количество подъездов. |
| **FLOORSMAX_... / FLOORSMIN_...** | Максимальное и минимальное количество этажей в здании. |
| **LANDAREA_...** | Площадь земельного участка. |
| **LIVINGAPARTMENTS_...** | Жилая площадь квартир. |
| **LIVINGAREA_...** | Общая жилая площадь. |
| **NONLIVINGAPARTMENTS_... / NONLIVINGAREA_...** | Нежилая площадь квартир / здания. |
| **FONDKAPREMONT_MODE** | Состояние фонда капитального ремонта. |
| **HOUSETYPE_MODE** | Тип дома (например, многоквартирный). |
| **TOTALAREA_MODE** | Общая площадь. |
| **WALLSMATERIAL_MODE** | Материал стен. |
| **EMERGENCYSTATE_MODE** | Находится ли здание в аварийном состоянии (Yes/No). |
| **OBS_30_CNT_SOCIAL_CIRCLE** | Количество наблюдений в социальном окружении клиента с просрочкой 30 DPD (дней). |
| **DEF_30_CNT_SOCIAL_CIRCLE** | Количество дефолтов в социальном окружении клиента с просрочкой 30 DPD. |
| **OBS_60_CNT_SOCIAL_CIRCLE** | Количество наблюдений в социальном окружении клиента с просрочкой 60 DPD. |
| **DEF_60_CNT_SOCIAL_CIRCLE** | Количество дефолтов в социальном окружении клиента с просрочкой 60 DPD. |
| **DAYS_LAST_PHONE_CHANGE** | Сколько дней назад клиент сменил номер телефона. |
| **FLAG_DOCUMENT_2 ... 21** | Флаги предоставления клиентом различных документов (например, паспорта). |
| **AMT_REQ_CREDIT_BUREAU_HOUR** | Количество запросов в кредитное бюро за час до подачи заявки. |
| **AMT_REQ_CREDIT_BUREAU_DAY** | Количество запросов в кредитное бюро за день до подачи заявки. |
| **AMT_REQ_CREDIT_BUREAU_WEEK** | Количество запросов в кредитное бюро за неделю до заявки. |
| **AMT_REQ_CREDIT_BUREAU_MON** | Количество запросов в кредитное бюро за месяц до заявки. |
| **AMT_REQ_CREDIT_BUREAU_QRT** | Количество запросов в кредитное бюро за квартал до заявки. |
| **AMT_REQ_CREDIT_BUREAU_YEAR** | Количество запросов в кредитное бюро за год до заявки. |

## 2. Таблица: bureau.csv
*Информация о прошлых кредитах клиента, полученная из бюро кредитных историй (БКИ).*

| Column (Английский) | Description (Русский) |
| --- | --- |
| **SK_ID_CURR** | Идентификатор текущей заявки (связь с application_train). |
| **SK_ID_BUREAU** | Идентификатор кредита в БКИ (каждая строка - отдельный кредит). |
| **CREDIT_ACTIVE** | Статус кредита в БКИ (закрыт, активен и т.д.). |
| **CREDIT_CURRENCY** | Валюта кредита в БКИ. |
| **DAYS_CREDIT** | Сколько дней назад клиент подал заявку на этот кредит в БКИ. |
| **CREDIT_DAY_OVERDUE** | Количество дней просрочки по кредиту в БКИ на момент текущей заявки. |
| **DAYS_CREDIT_ENDDATE** | Оставшееся количество дней до погашения кредита в БКИ. |
| **DAYS_ENDDATE_FACT** | Количество дней с момента фактического закрытия кредита в БКИ. |
| **AMT_CREDIT_MAX_OVERDUE** | Максимальная сумма просрочки по данному кредиту за все время. |
| **CNT_CREDIT_PROLONG** | Сколько раз кредит пролонгировался (продлевался). |
| **AMT_CREDIT_SUM** | Текущая сумма кредита в БКИ. |
| **AMT_CREDIT_SUM_DEBT** | Текущий долг по кредиту в БКИ. |
| **AMT_CREDIT_SUM_LIMIT** | Текущий кредитный лимит по кредитной карте в БКИ. |
| **AMT_CREDIT_SUM_OVERDUE** | Текущая сумма просрочки по кредиту в БКИ. |
| **CREDIT_TYPE** | Тип кредита (потребительский, ипотека, автокредит и т.д.). |
| **DAYS_CREDIT_UPDATE** | Сколько дней назад появилась последняя информация о кредите в БКИ. |
| **AMT_ANNUITY** | Аннуитетный платеж по кредиту в БКИ. |
